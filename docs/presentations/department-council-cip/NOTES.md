# Department Council presentation — source notes

Deliverable: `CIP_Department_Council_Presentation.pptx` (16:9, 11 slides, fully editable).
Generated by `build_deck.js` (pptxgenjs). Re-run with `node build_deck.js` from this folder.

## Audience and framing

Department Council, faculty, and program leadership. CIP is presented as a Curriculum
Committee software asset that supports curriculum **visibility, review, alignment,
documentation and continuous improvement**. It is explicitly *not* presented as a
replacement for official accreditation or assessment systems.

Scope: **Undergraduate Electrical Engineering only.** MSc/graduate modules exist in the
codebase but are referenced once, as "under construction / pending approval".

## Language guardrails observed

- GitHub Pages is described as *public static hosting that did not match our data-governance
  requirement* — never as "insecure".
- No DRM claim, and no claim that an authorized user cannot inspect local files. The stated
  objective is "controlled access, controlled distribution, reduced public exposure, release
  integrity, and managed synchronization of authorized local copies."
- macOS is stated as *not yet built*: "Windows is the first validated desktop platform."
- CIP "supports" review and documentation; it does not replace accreditation systems.
